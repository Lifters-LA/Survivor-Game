# Survivor Game

Survivor Game is a real-time multiplayer PvP game built with Phaser and Socket.IO.

Two players join the same match, fight enemies, compete for the gem, and try to survive longer than their opponent.


## Live Demo

[Play the Game](https://jearonajaromal.itch.io/survivor)

## Features

* Real-time 1v1 multiplayer
* Online matchmaking
* Socket.IO player synchronization
* Enemy patrol and chase behavior
* Melee combat
* Player health and respawning
* Gem pickup objective
* Win condition when the opponent is eliminated
* Tile-based game map
* Sound effects and background music

## Tech Stack

* **Frontend:** Phaser, JavaScript, HTML, CSS
* **Backend:** Node.js, Express, Socket.IO
* **Deployment:** Render, itch.io
* **Version Control:** Git, GitHub
